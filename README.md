# Vision Media Communications

Next.js 14 site. Run `npm install`, then `npm run dev`.

Pages live in `app/`, shared parts in `components/`, content in `data/`.
Colours and fonts: `app/globals.css` (variables at the top) and `tailwind.config.ts`.
Founder photos: `public/team/`. Photo frames are 4:5 and anchored to the top.
